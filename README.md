# Rock-Paper-Scissors-Python

a Python program that plays Rock, Paper, Scissors against the computer.

## Features

- Dynamic score tracking
- Automatic input validation (handles extra spaces and typos)
- Case-insensitive input mapping
- Automatic game termination when a player hits 10 points

## Concepts Used

- random module
- Strings (manipulation using `.strip()` and `.lower()`)
- Loops (`while` game loop)
- Conditional Statements (`if/elif/else` victory checks)

## How to Run

```bash
python rock_paper_scissors.py
```
